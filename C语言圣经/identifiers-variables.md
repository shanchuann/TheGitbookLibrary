# 标识符,变量

### 标识符

为变量,函数,结构体等起的名称

命名规则

>由下划线"_",英文字母(A-Z,a-z)和数字(0-9)构成,首字符必须是下划线或英文字母,不能由数字开头
>
>标识符命名尽量做到"见名知意"
>
>不能把C语言的关键字作为用户标识符
>
>标识符长度由系统决定(c89限制8字符,c99允许任意长度)
>
>标识符大小写敏感 

变量:以某标识符为名字,可读可写

```c
数据类型 变量名;//定义变量的格式
```

声明: 告诉编译器名字已经匹配到一块内存上,别的地方不能使用

定义创建了对象并为其分配一块内存,声明则没有分配

```c
int sum = 10; 
float pi = 3.14f;
char ch = 'a';
```

### 变量的作用域

#### 全局变量

函数外定义 

#### 局部变量

函数中定义

#### 块作用域

函数内部,复合语句中定义

```c
int c = 500;
int main(void){
	int a = 100;
	int b = 200;
	{
		int a = 0;
		printf("%d\n",a);//0
	}
	b = a + 10;//110
	printf("%d",b);//110
	return 0;
}
//::作用域解析符,C++支持
```
### static

1. 隐藏

​	当我们同时编译多个文件时，所有未加 static 前缀的全局变量和函数都具有全局可见性,如果加了就会对其他源文件隐藏

​	利用这一特性就可以在不同命的文件中定义同名函数和变量而不必担心命名冲突

​	static 可以用作函数和变量的前缀,对于函数来讲,static 的作用仅限于隐藏,而对于变量,static 还有以下作用

2. 保持变量内容的持久

​	储存在静态数据区的变量会在程序刚开始运行时完成初始化,也是唯一一次初始化

​	共有两种变量存储在静态存储区:全局变量和 static 变量,和全局变量比较,static 变量可以控制变量的可见范围,说到底static 还是用来隐藏的

3. 默认初始化为0

​	全局变量也具有这一属性

​	在静态存储区,内存所有字节的默认值都是0x00

static修饰的变量

在局部变量前加上static 关键字,局部变量就被定义为一个局部静态变量

1.  内存中的位置:静态存储区

2. 未初始化的局部静态变量初始化为0

3. 作用域:作用域仍为局部作用域,当定义他的语句块或函数结束的时候,作用域随之结束

   > 当 static 用来修饰局部变量的时候,他改变了局部变量的存储位置,从原来的栈中存放到静态存储区
   >
   > 但局部变量离开作用域后,并没有被销毁,而是仍然驻留在内存当中,直到程序结束,只不过我们不能对他进行访问
   >
   > 当 static 修饰全局变量,就改变了全局变量的作用域(声明文件之外不可见),但没有改变他的存放位置

static 修饰的函数

​	在函数的返回类型前加上 static ,函数就被定义为静态函数

​	函数的定义和声明默认情况下时 extern 的,声明后则其他文件不可见

​	定义静态函数的好处

1. 其他文件定义同名函数不会发生冲突
2. 静态函数不能被其他文件所用
