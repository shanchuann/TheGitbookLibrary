# C程序

```c
//hello.c                      //注释 /* */不允许嵌套使用
#include <stdio.h>             //预编译处理
int main(void)                 //主函数 程序入口
{
	printf("Hello World");     //语句
	return 0;
}
```

### C源程序结构特点

	- 一个c程序可以由一个或多个源文件组成

 - 每个源文件可以由一个或多个函数组成
 - 一个源程序只能有一个main函数
 - 每一个说明,每一个语句必须以 ; 结尾
 - 标识符,关键字之间必须有一个空格以示间隔,若以有明显标识符,则可以不用
