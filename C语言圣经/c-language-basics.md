# C语言基础

## C语言编译链接过程

### 过程

​	源文件( *.c源文件/ *.h头文件 )

​	预处理( *.i预编译文件 )                     gcc -E main.c -o main.i

​	编    译( *.s汇编文件 )(从上到下)      gcc -S main.i -o main.s

​	汇    编( *.o/ *.obj二进制目标文件 ) gcc -c main.s -o main.o

​	链    接( *.exe可执行文件 )                gcc -o main.o -o main

​	执    行 --> 进程(从main函数开始)

### 预处理	

​	概念：C语言源代码编译成可执行程序的第一阶段，主要处理宏替换、头文件展开和条件编译。

​	语法:预处理指令 表达式

#### 宏替换(宏展开)

预处理过程中,将变量,数据或表达式用容易理解的形式进行替换

#define 宏名 要替换的内容

为了提高程序阅读性,增强编码效率

```mermaid
flowchart LR
    A[源文件] --> B[预处理器]
    B --> C[宏展开]
    C --> D[展开后的 C 源码]
    D --> E[编译器]
```

特点:不做类型检查,仅仅是字符串的替换

#### 头文件展开

将头文件内容替换进当前程序

```mermaid
flowchart LR
    A[#include "header.h"] --> B[查找头文件]
    B --> C[插入声明与宏]
    C --> D[继续预处理]
```

## C程序

```c
//hello.c                      //注释 /* */不允许嵌套使用
#include <stdio.h>             //预编译处理
int main(void)                 //主函数 程序入口
{
	printf("Hello World");     //语句
	return 0;
}
```

### C源程序结构特点

	- 一个c程序可以由一个或多个源文件组成

 - 每个源文件可以由一个或多个函数组成
 - 一个源程序只能有一个main函数
 - 每一个说明,每一个语句必须以 ; 结尾
 - 标识符,关键字之间必须有一个空格以示间隔,若以有明显标识符,则可以不用

## 进制转换

​	X进制:逢X进1

 - 二,八,十六进制转十进制

   按位权展开后求和 e.g. 1010 --> 0 * 2^0^ + 1 * 2^1^ +0 * 2^2^ + 1 * 2^3^ = 10

   ( 二进制位权: 128 64 32 16 8 4 2 1 )
